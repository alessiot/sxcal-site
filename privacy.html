Privacy Policy

Last updated: September 2, 2026

SX/Cal is a calendar assistant app. This policy explains, in plain terms, what SX/Cal does and doesn't do with your data. If a sentence here doesn't match what the app actually does, that's a bug in this document, not license to assume otherwise — treat the app itself as the source of truth and tell us.

The short version

  • Your calendar, notes, and reminders are stored on your device, not on any server SX/Cal operates — because there isn't one.
  • The text you send SX/Cal (chat messages, reminders, photos you attach) is sent to OpenAI, using your own OpenAI API key, to be understood. SX/Cal has no OpenAI key of its own and nothing passes through an SX/Cal server in between.
  • Nothing is sold. There is no advertising, no analytics, and no tracking of any kind, by SX/Cal or by any third party embedded in the app.

What SX/Cal stores, and where

DataWhere it livesLeaves this device?
Events, notes, and reminders you create in SX/Cal This device (local database) Only if you turn on iCloud Sync (below)
Your OpenAI API key This device's Keychain (encrypted by iOS) Only in the Authorization header of requests you send to OpenAI
Your real Calendar's events (read-only) Apple's own Calendar database, unchanged No — read locally to check conflicts and free time; never uploaded, never modified by SX/Cal

iCloud Sync is off by default. If you turn it on (Settings), your events, notes, and reminders sync via Apple's own iCloud/CloudKit under your own Apple ID — governed by Apple's privacy policy, not this one. SX/Cal has no separate server-side copy of this data either way.

What's sent to OpenAI, and why

SX/Cal is a natural-language app: understanding "move my dentist appointment to Friday" requires sending that text to a language model. SX/Cal uses OpenAI's API for this, with the API key you provide in Settings — never a key SX/Cal supplies.

What's sent, only when you actually make a request:

  • The text of your chat message, reminder, or "remember this" request.
  • Your existing event titles/times (not full note contents) as context, so the model can resolve something like "move my 3pm to 4."
  • If you attach a photo (photo-to-event), the photo itself, sent to OpenAI's vision model to read schedule-relevant details from it.

This goes directly from your device to OpenAI's API — never to a server SX/Cal operates, because none exists. Your use of OpenAI's API is subject to OpenAI's own privacy policy and API data usage policy, which (as of this writing) states that API data isn't used to train OpenAI's models by default. Review OpenAI's current policy directly for specifics, since it can change independently of this document.

Moments (the on-device feature connecting your notes to today's calendar) does not send anything to OpenAI — its matching runs entirely on-device using Apple's own on-device language model (NLContextualEmbedding), built into iOS.

Other services SX/Cal uses

  • Weather (shown in the chat greeting): your approximate location (from iOS's own location permission, "while using the app") is sent to Open-Meteo, a free weather API, to fetch the local forecast. Open-Meteo doesn't require an account or API key, and SX/Cal sends only coordinates, nothing identifying you personally.
  • Apple Calendar (EventKit): read-only, with your explicit permission, to check for conflicts and free time against events from your real Calendar app. SX/Cal never writes to, modifies, or deletes anything in your real Calendar.

No analytics SDK, crash reporter, or advertising network is included in SX/Cal at all — not a reduced-tracking version, not present in the app whatsoever.

Your controls

  • Remove your API key at any time in Settings — SX/Cal stops working until you add one back (it's required to function), but nothing about removing it deletes your calendar data.
  • Delete SX/Cal's Data & Start Fresh (Settings) permanently deletes every event, note, and reminder SX/Cal has stored, on this device and in iCloud if sync was on. This cannot be undone. It never touches your real Calendar app's own events.
  • Deleting the app removes its local data (events, notes, reminders, your saved key) the same way deleting any iOS app does, except iCloud data if sync was ever turned on — use "Delete SX/Cal's Data" first if you want a clean removal from iCloud too.

Children's privacy

SX/Cal is not directed at children under 13 and does not knowingly collect data from them.

Changes to this policy

If what SX/Cal sends or stores changes in a future update, this page will be updated to match, with the "Last updated" date above revised accordingly.
